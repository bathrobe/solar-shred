# Solar Shred

A local tactical skate RPG prototype. Ride a skateboard-space-shuttle inward through an invented solar system, win trick battles, upgrade a heat shield, and reach the Sun-core treasure.

## Run locally

This project needs Node.js 20+ and pnpm.

```bash
pnpm install
pnpm dev
```

Open the local URL printed by Vite.

## Demo route

1. Select **Start run**.
2. Select **Drop in** at Neptune Drift.
3. Win the battle by using Kickflip, Grind, and Boost.
4. Claim Stardust, install the heat shield, then complete Mercury Rail and The Sun Core.
5. Select **Start new run** from the treasure ending.
